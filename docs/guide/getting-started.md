# شروع کار با Qbit Console

Qbit Console برای مدیریت **سرورهای شخص ثالث متعلق به شما** طراحی شده است. ثبت یک سرور در Qbit به معنی خرید، ساخت یا انتقال مالکیت آن سرور نیست.

## پیش‌نیازها

برای شروع به این موارد نیاز دارید:

- یک حساب Qbit Account؛
- دسترسی به یک فضای کاری (Workspace) یا مجوز ساخت فضای کاری جدید؛
- اطلاعات شناسایی سرور ریموت مانند hostname، IP یا یک remote reference معتبر؛
- در صورت استفاده از مدل SSH یا Agent، تنظیمات اتصال متناظر که توسط محیط عملیاتی شما مدیریت می‌شود.

## ورود به پنل

ورود پنل از طریق Qbit Account و OIDC انجام می‌شود. اگر چند حساب مرورگری داشته باشید، می‌توانید از بخش تنظیمات بین حساب‌ها جابه‌جا شوید. با تغییر حساب، context فضای کاری و داده‌های cached مرتبط با حساب قبلی پاک می‌شود.

## مسیر پیشنهادی راه‌اندازی

1. وارد Qbit Console شوید.
2. یک Workspace انتخاب یا ایجاد کنید.
3. اعضا و نقش‌های Workspace را بررسی کنید.
4. از بخش **Infrastructure → Servers** یک سرور ریموت اضافه کنید.
5. نوع اتصال، remote reference و metadata اختیاری را ثبت کنید.
6. پس از فعال‌شدن enrollment، آخرین وضعیت منابع سرور را بررسی کنید.
7. در صورت نیاز ruleهای هشدار و مقصدهای اعلان را تنظیم کنید.

## مفاهیم مهم

### Workspace

مرز سازمانی داده‌ها و دسترسی‌هاست. سرورها، اعضا، اعلان‌ها و اطلاعات billing در context یک Workspace نمایش داده می‌شوند.

### Remote server

رکورد کنترلی Qbit برای یک سرور شخص ثالث است. خاموش‌کردن یا حذف چرخه عمر این رکورد لزوماً عملیاتی روی خود ماشین اجرا نمی‌کند.

### Passive resource snapshot

وضعیت منابعی است که Qbit قبلاً دریافت و پذیرفته است. بازکردن صفحه جزئیات یا تاریخچه، polling جدیدی روی سرور اجرا نمی‌کند.
