# تنظیمات

صفحه Settings تنظیمات شخصی پنل و sessionهای حساب را یکجا مدیریت می‌کند.

## زبان و جهت رابط

Qbit Console از فارسی و انگلیسی پشتیبانی می‌کند:

- فارسی به‌صورت پیش‌فرض RTL است؛
- انگلیسی به‌صورت پیش‌فرض LTR است.

## تقویم

می‌توانید تقویم Gregorian یا Jalali را مستقل از زبان انتخاب کنید. در حالت «پیروی از زبان»، فارسی از Jalali و انگلیسی از Gregorian استفاده می‌کند. اگر تقویم را دستی override کنید، تغییر زبان انتخاب تقویم را بازنویسی نمی‌کند.

## حالت نمایش

Light و Dark mode هر دو در design system پشتیبانی می‌شوند. تنظیمات reduced motion سیستم نیز در رابط رعایت می‌شود.

## مدیریت حساب‌ها

در همان صفحه می‌توانید sessionهای حساب مرورگر را مشاهده، حساب فعال را تغییر، حساب اضافی را حذف یا sign out کنید.

::: tip
اگر بعد از تغییر حساب هنوز route یک Workspace قبلی را می‌بینید، از navigation اصلی وارد Workspace معتبر حساب جدید شوید. Qbit هنگام account switch context و query state حساس را بازنشانی می‌کند، اما URL مرورگر ممکن است به route قبلی اشاره کند.
:::
