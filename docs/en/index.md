## What this documentation covers

These docs focus on the currently implemented customer-console surfaces: accounts and workspaces, remote-server inventory, passive resource monitoring, alerts and notification destinations, read-only billing visibility, and panel preferences.

::: warning Product boundary
Qbit Cloud compute, application/database deployment, DNS, hosted registry/npm cache, wallet, and related hosted-service surfaces are currently **Coming soon** previews and are not operational workflows.
:::
