# Coming soon

Qbit Console includes reserved navigation areas that communicate the product direction. Their presence does not mean those workflows are operational.

## Current preview-only areas

The following surfaces are currently **Coming soon**:

- Qbit-hosted cloud compute;
- application deployment;
- database management;
- backup services;
- templates;
- Git-provider integrations;
- managed DNS;
- push-notification services;
- hosted container registry;
- hosted npm cache;
- wallet;
- hourly hosting metering.

## Currently operational areas

Use the implemented surfaces for:

- Workspace and membership management;
- remote-server inventory;
- passive resource monitoring and retained history;
- resource alert rules;
- webhook notification destinations and delivery history;
- read-only billing visibility;
- panel preferences and account sessions.

::: warning
Do not plan production operations around a preview until the Console exposes a real workflow and the feature is no longer marked Coming soon.
:::
